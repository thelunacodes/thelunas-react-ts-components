# TheLuna's React Typescript Components


<br>
<br>

#### 1. About the project

This project, as you may have already guessed, is a compilation of many React components created by me in my free time.

The components in this repository were written in **Typescript**. I intend to create a "TheLuna's React *Javascript* Components" in the future, but in the meantime, you're free to adapt these components for use in React projects using Javascript, as long as you credit me.

<hr>

#### 2. Requirements

1. An IDE of your choice (Visual Studio Code, for example)
2. Node.js (v20 or greater)
3. A Git client of your choice (Git Bash, for example)

<hr>

#### 3. How to install (using a terminal)

**Step 1:** Open the Git client. At first, you'll probably find yourself in the current user's home directory.

If you want to store the project files in a different location, use:

    cd <path/to/folder>

*(replace the '<path/to/folder>' with the actual path)*

The command above will change the current working directory in the terminal.

**Step 2:** Clone the project using:

    git clone https://github.com/thelunacodes/thelunas-react-ts-components.git

#### 4. How to run

This project includes a demonstration page showcasing the components created for this project. If you only want to use the components in your project, skip to the next section.

**Step 1:** Navigate to the project's root folder if you haven't done so already.

    cd <path/to/thelunas-react-ts-components>

**Step 2:** In the terminal, run:

    npm install

This command will install all the dependencies listed in the ``package.json`` file.

**Step 3:** After the installation has finished, run:

    npm run dev

<hr>

#### 5. Using the components in your project


Some of the components in this project use *Font Awesome icons*. You can either add the required dependencies to your project's ``package.json`` file, or follow the guide in the [official documentation](https://docs.fontawesome.com/web/use-with/react/).

**Important:** If you're manually adding the dependencies to your ``package.json`` file, you'll need to run:

    npm install

After that, simply copy the components located in ``src/components`` into your project.
